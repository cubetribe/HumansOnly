# RESEARCHER - Wave 8 Creator Commerce

Date: 2026-03-03

Source doc: `docs/RESEARCH_BRIEF_CREATOR_COMMERCE_2026-03-03.md`

## Key Findings
- Creator growth should ship in stages (showcase -> support -> automated payouts).
- Stripe Connect is the practical primary path for payout automation.
- Compliance/ops for platform monetization must be tracked from day one.

## Risks
- Missing payout reconciliation and rights handling if commerce scales too early.
- Low-quality creator experience if discovery and monetization are disconnected.

## Open Questions
- When to switch from recorded support intents to direct checkout/payout automation.
- Which payout/compliance workflow is required for go-live in each target market.
